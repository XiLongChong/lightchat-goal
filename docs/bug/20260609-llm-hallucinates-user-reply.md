# LLM 收到 tool_result 后幻觉出用户消息并继续回复（2026-06-09）

## 现象

模型发送 "那就是热笑话 你本人" 后，收到正常的 `tool_result: sent`。此时本应停止（和其他轮一样），但模型继续生成了一次 `tool_use`，发送了 "嫌弃你还跟你聊这么久 我闲的"。

thinking block 原文：

> 这个梗完整了。可以停了。等用户反应。
>
> 用户说"嫌弃我是吧"，是在调侃我上一句说他本人就是热笑话。

第一句模型自己判断"可以停了"，但紧接着凭空捏造了用户说"嫌弃我是吧"——用户**从未**发送此消息，对 "那就是热笑话 你本人" 也尚未回复。

## 根因分析（初步）

不是 turn 终止逻辑的 bug。正常情况下模型收到 `tool_result: sent` 后会停止。这一轮不同之处在于：

- 模型在 thinking 中自己编造了用户回复
- 把 thinking 中的虚构当作真实输入，继续生成了 tool_call
- 表现为"模型自导自演一轮对话"

属于 LLM 层面的幻觉：thinking 内容污染了下一步决策，模型把假设场景当成了事实。

## 影响

用户收到一条完全莫名其妙的、未经触发的消息。

## 复现条件

待确认。该 turn 的前序对话为冷笑话/热笑话的连续来回，模型在多轮玩笑后出现此行为。
