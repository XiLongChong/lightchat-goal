# 天气工具只能获取当前天气（2026-06-11）

## 现象

用户询问“明天天气”时，Agent 调用：

```json
{
  "location": "成都"
}
```

工具只返回当前天气：

```text
成都: Sunny +28°C 35% ↘21km/h
```

模型知道结果是当前天气，但仍根据当前温度推测明天“应该也差不多”，最终向用户发送：

```text
现在成都晴 28度 明天应该差不多 出门不用带伞
```

截图证据：

`C:\Users\MR\AppData\Local\Temp\codex-clipboard-28a48967-5c6b-41ab-8eb4-a02440754b01.png`

## 已确认原因

当前 `get_weather` 工具只有 `location` 参数。

实现请求：

```text
https://wttr.in/{location}?format=%C+%t+%h+%w&lang=zh
```

该格式只返回当前天气状况、温度、湿度和风速，没有日期参数或未来天气预报数据。因此工具无法回答明天或其他未来日期的天气。

## 影响

- 用户询问未来天气时，工具无法提供所需数据；
- 模型可能根据当前天气自行推测未来天气；
- 可能产生错误的出行或是否带伞建议。

## 期望行为

在天气工具支持预报前，Agent 不应将当前天气当作未来天气，也不应据此推测未来温度、降雨或出行建议。应明确说明当前只能查询实时天气。
